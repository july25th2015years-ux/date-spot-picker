# ふたりプラン (Futari Plan) 💕

佐賀県・福岡県でのデートで「何をするか」「どこに行くか」に迷ったカップルのための、カードをめくって新しいデートの選択肢を見つけられるWebアプリケーションです。

---

## 🌟 特徴と主な機能

1. **カードをめくるようなカルーセルUI**
   - 左右のスワイプ、ドラッグ、またはナビゲーションボタンで、トランプやカタログをめくるようにスムーズにデートプランを見比べることができます。
2. **佐賀・福岡の厳選デートプラン全60選**
   - 福岡県（32選）：糸島ドライブ、大濠公園スワンボート、天神大名カフェ、中洲夜景、門司港レトロ、柳川川下り、うきはフルーツ狩りなど。
   - 佐賀県（28選）：武雄市図書館、御船山楽園チームラボ、嬉野美肌温泉＆湯豆腐、呼子のイカ活き造り、有田ポーセリンパーク、大魚神社海中鳥居など。
3. **ワンタップ「キープ」機能**
   - 気になったプランをハートボタンで保存。LocalStorageでブラウザを閉じても保存されます。
   - キープ一覧画面で後からじっくり比較可能。
4. **LINE相談用テキスト生成**
   - シェアボタンを押すと、相手にそのまま送れる「ここ今度行ってみない？✨」のメッセージ文面とGoogleマップリンクを自動コピー。
5. **Googleマップ連携**
   - ワンタップで該当スポットのGoogleマップが開いてルートや詳細情報をチェック可能。
6. **エリア＆気分タグの簡単フィルター ＆ おまかせガチャ**
   - 都道府県（福岡・佐賀）や気分（まったり、絶景、グルメ、ドライブ、温泉、雨天OKなど）で絞り込み。
   - 迷った時は「🎲 おまかせガチャ」でランダムに運命のデート先を決定！
7. **オリジナルプラン追加機能**
   - ユーザー自身が行ってみたい場所や思いついたデートプランを追加・登録可能。

---

## 🛠️ 技術スタック

- **フロントエンド**: HTML5, Vanilla JavaScript (ES Modules), Tailwind CSS
- **アイコン**: Lucide Icons
- **デザイン**: カフェ風モダンデザイン（テラコッタ・ウォームベージュ基調）
- **データ管理**: LocalStorage（キープ、カスタムプラン）
- **ホスティング**: GitHub Pages

---

## 📱 使い方

ブラウザでURLを開くだけで、PC・スマホ問わずご利用いただけます。
スマートフォンでは、カードを左右に指でスワイプしてサクサクめくることができます。
